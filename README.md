# Intimatta — Pleasure Shop

Página de prueba de Intimatta: catálogo con cartas del Sextarot, perfumes propios y pedidos por WhatsApp.

- `index.html` — estructura de la página
- `styles.css` — estilos
- `app.js` — cartas, productos, carrito y armado del mensaje de WhatsApp
- `img/` — logo, cartas y frascos de perfume

## Cambiar productos o precios
Los productos están en `app.js`, en la lista `PRODUCTS`. Cada producto tiene nombre, categoría (`cat`), precio, precio anterior (`old`) y si hay stock. Para los perfumes, `price: null` muestra "Precio a confirmar".

## Publicar con GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / carpeta `/ (root)`.
